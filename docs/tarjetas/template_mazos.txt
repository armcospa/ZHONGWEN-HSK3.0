# Itinerario recomendado: mazos filtrados

Búsquedas para copiar y pegar. Las instrucciones completas están en el README
(sección «Itinerario recomendado: mazos filtrados»).

En cada mazo filtrado:
- Filtro 1: repasos de todos los niveles. Límite 9999, orden «Orden de revisión».
- Filtro 2 (marca la casilla para activarlo): nuevas del nivel que estés
  estudiando. Límite 10-15, orden «Orden añadido».
- Activa «Reprogramar tarjetas según mis respuestas».

Las dos búsquedas de un mismo mazo llevan el mismo «card:». Cuando termines un
nivel, cambia HSK1 por el siguiente solo en el filtro 2.


## Hanzi ← pinyin y significado (PM2H)

Filtro 1:  deck:"Chino - HSK*" card:PM2H is:due
Filtro 2:  deck:"Chino - HSK1 (HSK 3.0)" card:PM2H is:new


## Pinyin ← hanzi (H2P)

Filtro 1:  deck:"Chino - HSK*" card:H2P is:due
Filtro 2:  deck:"Chino - HSK1 (HSK 3.0)" card:H2P is:new


## Pinyin ← significado (M2P)

Filtro 1:  deck:"Chino - HSK*" card:M2P is:due
Filtro 2:  deck:"Chino - HSK1 (HSK 3.0)" card:M2P is:new


## Significado ← hanzi y pinyin (HP2M)

Filtro 1:  deck:"Chino - HSK*" card:HP2M is:due
Filtro 2:  deck:"Chino - HSK1 (HSK 3.0)" card:HP2M is:new


## Otras direcciones

El mismo patrón sirve con H2M, M2H, P2M, P2H o HM2P. Para consultar
«Toda la información», crea un mazo filtrado con un solo filtro,
card:"Toda la información", y desactiva la reprogramación.
